## C3 - generateFitnessProfile (2026-09-29)
- Done: packages/shared/src/profile-generation.ts (exported from the index): generateFitnessProfile(activities, now) -> { vdot, sources, benchmarks } | null. Input is a minimal ProfileActivity { id, name, sportType, startDate (ISO), distance (m), movingTime (s) }; D3's activity summary mapping should provide these fields (or map to them). Runs only (RUN_SPORT_TYPES), started within PROFILE_WINDOW_YEARS before `now` (future-dated runs ignored too).
